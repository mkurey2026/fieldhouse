# Fieldhouse

Southern Tier Youth Athlete Network, interactive pilot v2.

The website uses fictional athletes, grades, fixtures and scores. Real district names are geographic references only. No school or club partnership is claimed.

## Hosting
GitHub Pages: deploy from main, root folder. index.html, upgrade.css and upgrade.js form the buildless static website.

## Prototype boundaries
Role switching is a demonstration, not authentication. Operational demo progress saves in the visitor browser. Grades and coaching notes remain session-only. Do not enter real student information. No school, payment, social publishing or RevRing API is connected.

## Features
19 district selectors, 16 sections, club launch checklist, guided tour, media consent and revocation, moderation queue, score approvals, derived standings, fictional calendar download, athlete and coaching previews, architecture and association proposal.
